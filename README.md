An immersive, gamified developer portfolio inspired by **Grand Theft Auto VI (Leonida / Vice City)** and modern high-performance web architecture.

---

## ⚡ Features

- 🎮 **GTA VI HUD & Screen Navigation**: Complete Vice City HUD featuring live IST clock, Wanted Level stars, player health/armor bar, GPS minimap radar, and Leonida launch countdown.
- 🔊 **Studio-Grade Web Audio Synthesizer**: Custom Web Audio engine with mission-select chimes, arcade ticks, cyber telemetry dispatch sound, and retro 80s FM synth radio.
- 🔇 **Master Audio Control**: Dedicated one-click `AUDIO: ON / OFF` toggle and `'M'` key shortcut with persistent preferences.
- 📄 **Interactive Resume / CV Viewer**: Embedded PDF modal preview with instant download and direct tab viewing.
- 🚀 **Projects Showcase & Case Studies**: Deep-dive architectural case studies for Verixa, Smart Inventory, Smart GST, and Exertia.
- 📜 **Verified Coursera Certifications**: Direct verified credential links with trophy badges.
- 📡 **Working Secure Dispatch**: Interactive contact form with auto-formatted mailto triggers and guaranteed clipboard fallback.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, JavaScript (ES6+), Framer Motion, Lucide React
- **Styling**: Tailwind CSS v4, Custom CRT Scanlines, Neon Vice City Glows
- **Audio Engine**: Web Audio API with Master DynamicsCompressor
- **Build Tool**: Vite 8 with Oxlint

---

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/Zaidmemon5412/portfolio.git

# Navigate to project directory
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
